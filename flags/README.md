# Flag assets

Self-hosted 4:3 SVG flags from [flag-icons](https://github.com/lipis/flag-icons), version 7.5.0, MIT licensed. Only the 250 flags used by the country picker are included.

The country-code catalog comes from [i18n-iso-countries](https://github.com/michaelwittig/node-i18n-iso-countries), version 7.14.0 (MIT). It covers the ISO 3166-1 countries and territories plus Kosovo (XK). English display names were generated with Intl.DisplayNames. Country choices are self-reported by each player.
